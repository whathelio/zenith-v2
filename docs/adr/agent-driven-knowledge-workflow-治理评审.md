## 三、最小安全第一刀方案（MVP）

目标：在**不依赖外部 Docker 服务、不冒微信封号风险**的前提下，先验证“Zotero → 本地 RAG → 终端问答”这条核心数据链。

1. **保留承重内容**
   - “DeepSeek 当大脑、RAG 当记忆外挂”的解耦架构图。
   - “IMA 可借鉴、Agent 缺执行”的边界判断。
   - 技术选型列表（FastGPT/RAGFlow/Chroma/DeepSeek 等）。

2. **必须补上的内容**
   - Zotero 路径解析的具体 SQL/伪代码。
   - PDF 文字覆盖率检查与 OCR 回退逻辑。
   - 轻量本地 RAG 方案（Chroma + bge-small）。
   - 异步任务队列的必要性说明。

3. **可以暂缓或删除的内容**
   - FastGPT/RAGFlow 的完整 Docker 部署命令（移到“阶段 2 可选重型方案”）。
   - 微信/QQ 商业方案（知更 Ai）的详细配置，可保留一行链接。

## 六、审计结论

本文档作为“蓝图”方向正确，但当前版本若直接交给开发者落地，会在 **Zotero 路径解析、PDF 预处理、微信超时、资源占用、记忆设计** 五个地方卡壳。建议按“阶段 A”优先补全工程细节，并发布 `v2` 版本。v2 版本已按本报告意见完成修订，见 `agent-driven-knowledge-workflow-v2.md`。
