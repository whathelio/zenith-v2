> **建档日期**：2026-10-09 ｜ **建档方式**：`ls` 实测，不是凭记忆。

**约定**：
- 「维护者」= 谁有权写它。`运行时` = 服务/前端自动写，**人不要手改**；`whathelio` = 只有他能改；`Zenith` = agent 协作可改（改前 `cp` 备份）。
- 「🔴 承重」= 被代码引用或影响启动链路，改动必须走 ADR + 端到端验证。
- 路径前缀：`<root>` = `zenith-v2/`。
