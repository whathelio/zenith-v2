## 一、三条公理（来自数据，不是来自原则）

| # | 公理 | 实测 |
|:--|:--|:--|
| **A1** | **亏损全部来自「摊平」，不是来自「加仓」** | 含摊平的 19 个战役 −229.07；其余 44 个 +160.85 |
| **A2** | **顺势加是唯一强正期望的行为** | +16.76/笔，PF 83.77，最大单亏仅 −1.62（8 笔样本） |
| **A3** | **摊平会制造 63% 的胜率，然后亏掉 3.4 倍的均亏** | 均盈 +19.55 / 均亏 −66.24 |

推论：**唯一必须机械禁止的动作是「摊平」**。禁止加仓属于过度纠偏，会把 A2 一起禁掉。

### A1 的必要补充：摊平在短期会连续赢

| 窗口 | 含摊平 | 纯顺势加 |
|:--|--:|--:|
| 9-21 ~ 10-18（27 天） | **−399.50**（15 笔，期望 −26.63，PF 0.14） | +134.08（8 笔，期望 +16.76） |
| 10-19 ~ 10-20（2 天） | **+170.43**（4 笔，**100% 胜率**） | **0 笔** |

**同一个动作，27 天亏 400，2 天赚 170。** 而 10-19/10-20 这两天**一次顺势加都没有** —— 赚钱的时候用的正是唯一负期望的动作。

> 执行这条规则的第一个月，你会看着摊平连续赢。这不是规则错了，是负期望的正常表现。
> **规则生效的判据不是「这几笔赚没赚」，是「摊平次数是否为 0」。**

**摊平 / 顺势加的机械判据**（不看盈亏，看价格）：

```
多头：新腿价 < 当前持仓均价  → 摊平（禁止）
      新腿价 > 当前持仓均价  → 顺势加（允许，见 S4）
空头：新腿价 > 当前持仓均价  → 摊平（禁止）
      新腿价 < 当前持仓均价  → 顺势加（允许）
```

> 均价 = Σ(价格×手数)/Σ手数，只算**当前未平部分**。

## 二、状态机

```
S0 定位 → S1 资格 → S2 开仓 → S3 持仓监控 → S4 加仓判定 → S5 出场 → S6 复盘
                              ↑______________|
```

### S0｜定位（每轮对话第一次，或价格穿越关键位时）

| 读数 | 来源 | 用途 |
|:--|:--|:--|
| POC / VA 上下沿 | `mt5_volume_profile(M15, 300)` | 判「价值区内/外」 |
| 近 24h 高低 | `mt5_rates(M15, 96)` 的 high/low | 博弈带基准 |
| 当日高低 | `mt5_rates(M30/D1)` | 同上（口径必须写明） |
| 点差 | `mt5_tick` | > 0.5 → 冻结 |

🔴 **VA 读数必须带窗口参数与时刻**，且同一天重算过两次就以最新一次为准（算法未修期间，VA 边界会漂 20+ 美元）。

### S1｜开仓资格（4 条 AND，全过才允许开首腿）

| # | 条件 | 读数 | 不满足 |
|:--|:--|:--|:--|
| 1 | 距最近已确认高/低点 **> 10 美元** | S0 的高低点 | 观察，不开 |
| 2 | 三维度同向（连续 ≥3 根 M5 / 位移÷量 高于 20 根均值 / 回撤 <40%） | 人工读，需记数 | 不开 |
| 3 | 手数 = `floor(余额/100) × 0.01`，且 SL 距离 ≤ 5.5 美元 | `mt5_account` + 结构位 | 放弃或等更好位置 |
| 4 | 今日 campaign 数 < 2，且上一笔平仓距今 ≥ 30 分钟 | 日志 | 不开 |

**禁止时段**：数据发布前后 15 分钟。

### S2｜开仓

- 手数按 S1-3 一次给足（0.03 手 = 3 份，为后续减仓留步进）
- **SL 必须随单挂上**，不挂不下单
- 记录一行日志：时间 / 方向 / 价位 / 手数 / SL / 三维读数 / 位置分类

### S3｜持仓监控（每 15 分钟或价格穿越关键位时）

| 回撤（相对推进幅度） | 位置 | 动作 |
|:--|:--|:--|
| < 40% | 博弈带外 | 持有，SL 不动 |
| < 40% | 博弈带内 | **减 1 份（0.03→0.02）+ SL 移保本** |
| 40–60% | 博弈带外 | 持有，SL 上移至 −2.75（半风险） |
| 40–60% | 博弈带内 | **减 1 份 + 此后禁止任何加仓** |
| **> 60%** | 任意 | **平仓**（推进已废，不问盈亏） |

### S4｜加仓判定（这是 v1.0 相对旧规则的**唯一实质改动**）

| 新腿价 vs 均价 | 判定 | 动作 |
|:--|:--|:--|
| 有利侧（多头更高 / 空头更低） | **顺势加** | 允许，但**总量不得超过 S1-3 的上限**；且必须在价格已走出推进幅度 40% 之后 |
| 不利侧（多头更低 / 空头更高） | **摊平** | 🔴 **绝对禁止**。唯一的例外是 §5 的闪崩锁仓 |

**判定必须在下单前做，不能事后解释**：开盘同时把「当前均价」写在纸上，新价一比对就知道。

### S5｜出场

按 S3 触发的减仓 / SL / 目标位。**优先一次平完**（实测 81% 的战役是 ≤60 秒内齐平，且分批平仓在 10-20 少赚 9.62）。

若 S3 已执行过减仓，则剩余仓位只走 SL 或目标，**不补回**。

### S6｜复盘（当日收盘后，5 分钟）

用 campaign 口径，不用 position 口径：

```bash
cd zenith-v2
.venv/Scripts/python.exe tools/campaign_report.py --days 7 --symbol XAUUSD -v
```

检查四项，**只看第一项是否为零**：

| # | 指标 | 达标线 |
|:--|:--|:--|
| 1 | **摊平战役数（`含摊平腿`）** | **0** |
| 2 | 单日 campaign 数 | ≤2 |
| 3 | 最大敞口增长（`exposure_growth`） | ≤1.0（不允许越加越大） |
| 4 | 齐平率（`flat_close_pct`） | 记录即可，不设目标 |

## 三、与旧规则的冲突及裁定

| 冲突项 | 旧（635/636/2731/2745） | 本文裁定 | 理由 |
|:--|:--|:--|:--|
| 单笔风险 | 1.5%（3.17 USD） | **≤5.5%（SL 5.5 美元 × 0.03 手）** | 0.03 手要满足 1.5% 需 SL=1.82 美元，小于点差+噪音，**数学上不可执行** |
| 手数 | 固定 0.02 / `floor(余额/100)` | **`floor(余额/100)×0.01`**（当前 0.03） | 随账户自动缩放，爆仓距离锁在 100–200 美元 |
| 日上限 | ≤3 笔 / ≤2 笔 | **≤2 个 campaign** | 笔数在 hedging 下无意义（1 次决策 = 5 笔） |
| 加仓 | 浮亏加仓次数 = 0 | **摊平 = 0；顺势加允许** | A1+A2 |
| 减仓 | 「减一半」 | **0.03 只能按 1/3 步进**（→0.02→0.01） | 减 50% = 0.015 手，不存在这个数量 |

## 五、异常情形（不进状态机，硬规则）

| 情形 | 动作 |
|:--|:--|
| 点差 > 0.5 | 冻结所有动作（含平仓，等回落） |
| 跳空 / 闪崩 > 3 美元 | **允许锁仓** —— 这是对冲的唯一合法情形 |
| 连亏 2 个 campaign | 当日结束 |
| 距爆仓 < 100 美元 | 禁止开仓（当前 363.73 / 0.03 → 121.2，余量 21 美元） |
| 账户上台阶（500 / 750 / 1000） | 提走当段盈利 50%，余额回落 |
