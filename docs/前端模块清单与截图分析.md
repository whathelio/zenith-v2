## 页面截图分析

### 1. DashboardView (`/`) — 01-dashboard.png

**功能：** 用户的主操作面板，整合了日历、目标追踪和今日内容。

**布局：** 三栏布局
- 左侧 (480px)：月历概览 + 目标进度卡片
- 右侧：今日焦点 + 当天日程/笔记/对话/记忆摘要

**数据来源：**
- `/api/calendar?year=2026&month=7`
- `/api/goals?status=`
- `/api/goals/:id/stats`
- `/api/reminders`

**状态：** ✅ 活跃使用

---

### 2. ChatView (`/chat`) — 02-chat.png

**功能：** SSE 流式 AI 对话界面，支持文件拖放上传分析、工具调用可视化。

**布局：** 全宽对话区 + 底部输入框
- 输入框支持文字 + 文件拖放
- 消息流式渲染
- 侧边栏可展开对话历史

**关键交互：**
- 文件拖放 → `/api/file/analyze`
- SSE 流式 → `/api/chat`
- 工具调用实时展示

**数据来源：**
- `/api/chat` (SSE)
- `/api/conversations`
- `/api/file/analyze`

**状态：** ✅ 核心功能，活跃使用

---

### 3. CalendarView (`/calendar`) — 03-calendar.png

**功能：** 周视图日历 + 事件 CRUD。

**布局：** 周视图网格 + 事件列表
- 上方：周导航（前后切换）
- 主体：7 列日视图
- 下方：今日事件列表

**关键交互：**
- 点击日期 → 创建事件
- 点击事件 → 编辑/删除

**数据来源：**
- `/api/calendar?year=&month=`
- `/api/schedules`

**状态：** ✅ 活跃使用

---

### 4. GoalsView (`/goals`) — 04-goals.png

**功能：** 目标追踪管理，支持进度条、日化收益计算、在轨/偏离检测。

**关键功能：**
- 目标创建/编辑/删除
- 进度条可视化
- 日化收益目标计算
- 在轨/偏离状态标记

**数据来源：**
- `/api/goals`
- `/api/goals/:id/stats`

**状态：** ✅ 活跃使用

---

### 5. KnowledgeView (`/knowledge`) — 05-knowledge.png

**功能：** RAG 知识库界面，PDF 上传 + 向量检索 + LLM Wiki。

**依赖：** 外部 `api_gateway.py` (端口 8788)

**关键功能：**
- PDF 上传入库
- 向量相似度检索
- LLM Wiki 生成

**数据来源：**
- `/api/knowledge/*` (转发到 api_gateway)

**状态：** ⚠️ 依赖外部网关，离线时显示 "Knowledge offline"

---

### 6. SettingsView (`/settings`) — 06-settings.png

**功能：** 系统配置页面。

**配置项：**
- API Key
- API Base URL
- 模型选择
- Temperature
- Max Tokens

**数据来源：**
- `/api/settings`

**状态：** ✅ 活跃使用

---

### 7-10. LibraryView (`/library`) — 07~10-*.png

**功能：** 统一资料库界面，整合笔记、记忆、技能三个子模块。

**Tab 切换：**
- `tab=notes` → 笔记 CRUD + AI 提议
- `tab=memories` → 记忆浏览/搜索/去重
- `tab=skills` → 技能卡片 CRUD + 匹配触发

**数据来源：**
- `/api/notes`
- `/api/memories`
- `/api/skills`

**状态：** ✅ 活跃使用
