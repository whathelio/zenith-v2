## 三、影响因素深度分析

### 📊 1. 美联储货币政策 (权重: ★★★★★)

**当前态势：**
- 6月CPI同比+3.5%(低于预期)，环比-0.4%(2020年4月以来首次负值)
- 6月PPI环比-0.3%(意外下降，远低于预期的持平)
- **7月加息概率从16.6%→10.2%，几近排除**
- 9月加息概率44%，12月加息概率70.9%
- Fed Chair沃什立场鹰派："Inflation is a choice"，对任何通胀指标不满意

**判断：** 短期(1-2周)通胀降温对黄金构成明确利好，但中期(1-3月)沃什鹰派立场+9名FOMC委员支持年内再加息，高利率维持周期拉长仍是压制因素。**净影响：短期偏多，中期偏空。**

### ⚔️ 2. 中东地缘冲突 (权重: ★★★★★)

**当前态势：**
- 特朗普宣布美伊谅解备忘录"已终结"，不想再同伊朗打交道
- 美军对伊朗沿海防御设施和导弹基地发动新一轮空袭
- 伊朗威胁切断更多地区能源出口通道(霍尔木兹海峡)
- 特朗普考虑3项升级方案：夺取哈尔克岛、轰炸镐山核设施、扩大能源打击
- 伊朗反击巴林、科威特、约旦境内美军目标
- 高盛估计海湾原油出口已降至战前50%(~1100万桶/日)

**判断：** 地缘冲突对黄金产生**双重效应**：
- 🔵 **避险需求**：直接推升黄金买盘，每次冲突升级金价短暂冲高
- 🔴 **通胀传导**：油价飙升→能源成本上涨→通胀反复→央行维持高利率→压制黄金
- **净影响：偏多但复杂，冲突升级→短期冲高→若油价持续高位→中长期反而利空**

### 💵 3. 美元指数 (权重: ★★★★☆)

**当前态势：**
- 美元指数从101.32(7月14)→100.55(7月16)，创6月中旬以来新低
- 10日趋势：101→100.5，持续走弱
- 美联储加息预期降温是主因
- 但美国经济表现优于其他主要经济体+海外资金对美元资产需求强劲

**判断：** 短期美元走弱利多黄金，但美元跌势可能难以持续。若油价持续高位推升通胀→美元可能重新走强。**净影响：短期偏多黄金，中期需观察美元能否在100关口企稳。**

### 🛢️ 4. 原油市场 (权重: ★★★★☆)

**当前态势：**
- WTI从68.43(7月3)→79.29(7月16)，涨幅超16%
- 布伦特84-85.6美元，接近一个月高位
- 中东冲突→供应中断风险→油价高企
- 但EIA库存降幅不及预期+馏分油大增460万桶→供应并未迅速消失
- 高盛警告：若出口恢复停滞，Q4布伦特可能突破110美元

**判断：** 油价是当前黄金分析的**关键变量**。若油价站稳80+持续走高→通胀二次抬头→黄金短涨长跌；若油价回落→通胀压力缓解→黄金可持续上行。**净影响：高度不确定，需动态跟踪。**

### 📈 5. 美股/风险偏好 (权重: ★★★☆☆)

**当前态势：**
- S&P 500 7572.42(+0.38%)，接近52周新高7620.9
- YTD涨幅10.62%
- 财报季开局强劲(贝莱德+6.6%，摩根士丹利超预期)
- PayPal被收购消息飙升17.2%
- 科技股分化：苹果+4%，SK海力士-9%

**判断：** 美股持续走强→风险偏好上升→资金从黄金流向股市→压制黄金。但若中东冲突真正升级→美股回调→避险资金回流黄金。**净影响：偏空黄金，除非地缘黑天鹅打破当前乐观。**

### 🏦 6. 黄金ETF资金流 (权重: ★★★☆☆)

**当前态势：**
- 全球黄金ETF从2月底至今累计净流出128吨(持仓缩水3%)
- JPM将2026年ETF预测从净流入400吨→净流出50吨(全年风向反转)
- 亚洲黄金ETF也转为净流出
- 但国内线下金店实物金条销量环比走高

**判断：** 机构持续减仓→资金面偏空。散户实物需求支撑有限，无法对冲国际盘抛压。央行购金节奏放缓(JPM将预测从640→600吨)。**净影响：中期偏空。**
